
# Employee Salary Prediction

## About the Project
This project focuses on predicting employee salaries using Python and machine learning techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Load the dataset.
2. Clean and preprocess the data.
3. Perform exploratory data analysis.
4. Train a machine learning model.
5. Evaluate the model's performance.

## Project File
- `Employee_Salary_Prediction.ipynb` — notebook containing the project code and analysis.
